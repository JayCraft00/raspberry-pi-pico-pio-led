# Raspberry Pi Pico PIO LED Distance Indicator

A MicroPython project using a Raspberry Pi Pico, HC-SR04 ultrasonic distance sensor, and an individual RGB LED.

## Overview

This project uses an HC-SR04 ultrasonic sensor to measure the distance between the sensor and an object. The Raspberry Pi Pico processes the distance measurement and controls an RGB LED to provide a visual indication based on the detected distance.

The project also uses the Raspberry Pi Pico's Programmable I/O (PIO) functionality for precise timing and LED control.

## Hardware

- Raspberry Pi Pico
- HC-SR04 ultrasonic distance sensor
- Individual RGB LED
- Resistors
- Breadboard
- Jumper wires

## Software

- MicroPython
- Thonny
- Raspberry Pi Pico `rp2` PIO functionality

## Concepts Demonstrated

- MicroPython
- GPIO control
- Ultrasonic distance measurement
- RGB LED control
- Timing and speed control
- Programmable I/O (PIO)
- Conditional logic
- Embedded programming
